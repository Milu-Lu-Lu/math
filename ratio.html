比與比例式 (七年級) vs 連比與連比例式 (九年級)

學習地圖與銜接

從「兩數量」到「多數量」的推廣關係

在七年級，我們學習了兩個數量的相對關係（比與比例式）；到了九年級，我們將這個概念擴展至三個或三個以上的數量（連比與連比例式）。理解兩者的相似與關鍵差異，是掌握國中幾何相似形與物理變量的基礎！

七年級：比與比例式 雙變數 $a : b$

1. 定義與表示法

比較兩個數量 $a$ 與 $b$ ($b \neq 0$)，記作 $a : b$。

比值為 $\frac{a}{b}$ （前項 $\div$ 後項）。

2. 核心等式性質

  • 交叉相乘： 若 $a : b = c : d$，則 $ad = bc$ （外項積 = 內項積）。
  • 同乘同除： $a : b = (a \cdot k) : (b \cdot k)$ ($k \neq 0$)。

3. 參數設法 (最常用技巧)

若已知 $a : b = 3 : 5$，可設定：

$a = 3r, \quad b = 5r \quad (r \neq 0)$
特點： 有單一確切的「比值」，計算直觀，可用分數直接表示。
九年級：連比與連比例式 多變數 $a : b : c$

1. 定義與表示法

同時比較三個或三個以上的數，記作 $a : b : c$。

注意：沒有所謂「連比值」（不能寫成 $\frac{a}{b}{c}$ 這種形式）。

2. 核心等式性質

  • 分拆比例： 若 $a : b : c = x : y : z$，代表 $a:b=x:y$ 且 $b:c=y:z$ 且 $a:c=x:z$。
  • 等比等式： $\frac{a}{x} = \frac{b}{y} = \frac{c}{z} = r$ ($x,y,z \neq 0$)。

3. 參數設法 (通用金鑰)

若已知 $a : b : c = 2 : 3 : 7$，可設定：

$a = 2r, \quad b = 3r, \quad c = 7r \quad (r \neq 0)$
致命誤區： 絕不能跨三項直接交叉相乘（如：$a \cdot b \cdot c \neq x \cdot y \cdot z$ 或 $ax = by = cz$ 皆為錯誤！）。

生活中的實例比較：從調飲到合夥創業

許多生活情境都會用到比的概念，讓我們看看從「2個元素」增加到「3個元素」時，數學模型是如何演進的！

情境一：飲料店配方

七年級 (兩項比) 經典鮮奶茶：
紅茶 : 鮮奶 = $3 : 2$
代表每 3 份紅茶就要搭配 2 份鮮奶。紅茶佔總量的 $\frac{3}{5}$。
九年級 (連比) 招牌珍珠鮮奶茶：
紅茶 : 鮮奶 : 珍珠 = $5 : 3 : 2$
總共分為 $5+3+2=10$ 份。若要調配 700ml 飲料，珍珠需 $700 \times \frac{2}{10} = 140$ml。

情境二：獎金與出資分配

七年級 (兩項比) 小明與小華合資買彩券：
出資額 小明 : 小華 = $100 : 200 = 1 : 2$。
中獎 900 元時，小華應拿小明的 2 倍（600 元）。
九年級 (連比) 三人合夥創業出資比：
小明 : 小華 : 小美 = $2 : 3 : 5$。
若年度盈餘 100 萬，小美可分得 $100 \times \frac{5}{2+3+5} = 50$ 萬。

情境三：圖形與建築模型

七年級 (兩項比) 長方形的長寬比：
長 : 寬 = $4 : 3$。
知道比例尺 1 : 1000 時，可由地圖長度推算實際長度。
九年級 (連比) 三角形的三邊長連比：
$a : b : c = 3 : 4 : 5$ (直角三角形)。
結合相似形，放大後的三邊長依然保持 $3:4:5$ 的連比例！
九年級關鍵技能

如何將兩個「雙項比」合併為一個「連比」？（尋找橋樑數）

假設已知「紅茶 : 鮮奶 = $2 : 3$」，且「鮮奶 : 糖漿 = $4 : 1$」，如何求出「紅茶 : 鮮奶 : 糖漿」？

Step 1： 找出共同項（橋樑）：鮮奶（分別佔 3 份與 4 份）。
Step 2： 求公倍數：$\text{LCM}(3, 4) = 12$。
Step 3： 同放大擴分： 紅茶:鮮奶 $= 2:3 = 8:12$； 鮮奶:糖漿 $= 4:1 = 12:3$。
最終結果：紅茶 : 鮮奶 : 糖漿 = $8 : 12 : 3$

/ 單元 01：課程導言
📐 概念啟航

課程導言：從「全等」走向「相似」

在先前的課程中，我們學過了證明三角形一模一樣的五大「全等性質」。今天我們要施展「縮放魔法」，把三角形放大或縮小。

🖨️
生活生動比喻

影印機的放大與縮小魔法

要理解「相似形」，最直觀的方法就是想像我們把畫有三角形的紙張放進超商的「影印機」：

原寸 100% 影印 k = 1.0

【全等】的化身

邊長 1:1 複製，角度完全一樣，印出來跟原本一模一樣！

放大 150% 影印 k = 1.5

【相似放大】

三條邊長都自動變為原稿的 1.5 倍，但三個內角度數完全沒變！

縮小 70% 影印 k = 0.7

【相似縮小】

三條邊長等比縮短為原稿的 0.7 倍，三個內角度數依然維持原狀！

💡

重點總結：不論你把影印機設成 $50\%$、$150\%$ 還是 $200\%$，影印出來的圖形形狀絕對不會變形走樣。因為機器保證了「每一條邊依照相同倍率伸縮」，而「每一個角度數完全原汁原味保存」！

⭐
核心黃金鐵律

在幾何縮放過程中，有兩個不可動搖的原則：

1

邊長會成比例改變

就像影印機放大 $k$ 倍（例如 $150\%$ 放大為 $1.5$ 倍），所有的對應邊長都會等比乘以 $k$。長度呈現固定的倍率比值。

2

角度永遠維持不變

無論影印放大或縮小多少倍，拿起量角器測量印出來的三個內角，角度數值絕對不會變大也不會變小！角度牢牢鎖定了圖形的形狀。

🔹 溫故：全等三角形（Congruence）

比例 1 : 1

全等代表圖形「形狀一模一樣」且「大小完全相同」。五大全等性質包括：

SSS SAS ASA AAS RHS
💡 全等本質上就是相似比為 $1:1$ 的特殊相似圖形！

✨ 知新：相似三角形（Similarity）

長度成比例 $1 : k$

相似代表圖形「形狀一模一樣」但「大小可以成比例放大或縮小」。透過縮放魔法，原本的 5 個全等條件將自然演化為：

SSS 相似 AA 相似 SAS 相似
🎯 接下來，讓我們看看這五大性質是如何優雅地轉化為三大相似性質！

/ 單元 03：SSS 相似與 RHS
🔺 核心性質推導 (一)

SSS 相似 (源自 SSS 與 RHS)

當三組對應邊長都被放大相同的倍數時，三角形的形狀就被唯一固定。同時，直角三角形的 RHS 也在這裡找到了它的縮放歸宿！

1
直觀幾何機制

SSS 的轉化

當三組對應邊長都被放大相同的倍數 $k$ 時（即 $\frac{A'B'}{AB} = \frac{B'C'}{BC} = \frac{C'A'}{CA} = k$），三角形的三條邊長唯一決定了其內部角度與形狀。

👉 這非常直觀：三邊等比例伸縮，形狀完全鎖定不變！

三組對應邊 $\frac{6}{3} = \frac{8}{4} = \frac{10}{5} = 2$，必為相似形！

2
代數深層揭密

RHS 的隱藏身分

❓ 為何 RHS（直角、斜邊、一股）會歸類在 SSS 相似？

在直角三角形中，只要斜邊與一股的長度成比例（例如斜邊放大 $k$ 倍、一股放大 $k$ 倍）：

勾股定理代數推導展示：
設原本直角三角形三邊為 $a, b, c$（$c$ 為斜邊，滿足以 $a^2+b^2=c^2$）
放大後的斜邊為 $kc$，已知的一股為 $ka$，則第三股 $b'$ 必定為：
$$b' = \sqrt{(kc)^2 - (ka)^2} = \sqrt{k^2(c^2 - a^2)} = k\sqrt{b^2} = k \cdot b$$

🎯 結論：第三邊必然也會呈現相同的比例 $k$！因此 RHS 在縮放後，本質上就完全滿足了三邊成比例的 SSS 相似。

/ 單元 04：AA 相似性質
📐 核心性質推導 (二) · 題型之王

AA 相似 (源自 ASA 與 AAS)

角度主宰形狀！幾何圖形在放大縮小的時候，角度是絕對不變的。

👑

角度主宰形狀

三角形的延伸方向與張角，完全由內角決定。幾何圖形在放大或縮小的過程中，角度具有百分之百的守恆性。

✨ 當兩個三角形所有對應內角都相等時，它們的「形狀」就已經注定一模一樣！
180°

為何簡化成了 AA？

因為三角形內角和固定為 $180^\circ$！

若 $\angle A = \angle A'$ 且 $\angle B = \angle B'$，則第三個角必然：

$$\angle C = 180^\circ - \angle A - \angle B = \angle C'$$

只要確認有「兩個內角」對應相等，第三個角就注定會一樣，形狀即被唯一確定！

🎯

出題率最高王牌

不管原本全等條件是夾邊 (ASA) 還是非夾邊 (AAS)，在縮放世界中都忽略了絕對邊長的限制。

🔥 考試秒殺秘笈：

在國中段考與會考中，AA 相似是使用頻率最高、最容易找出的相似證明性質（常搭配對頂角、同位角、內錯角、公共角）！

👀 AA 相似視覺解析示意

兩角相等（$\angle B=\angle E=70^\circ$ 且 $\angle C=\angle F=50^\circ$），兩圖形即使大小不同，形狀完全同構相似！

$\angle B = \angle E = 70^\circ$（第一組角相等）
$\angle C = \angle F = 50^\circ$（第二組角相等）
$\angle A = \angle D = 180^\circ - 70^\circ - 50^\circ = 60^\circ$（第三組角自動相等）
👉 結論：$\triangle ABC \sim \triangle DEF$（根據 AA 相似性質）
/ 單元 05：SAS 相似性質
👐 核心性質推導 (三)

SAS 相似 (源自 SAS)

夾角與伸展臂：想像相等的「夾角」是一個固定不變的關節。

🦾
生動比喻模型

夾角與伸展臂

1. 固定關節（等角）：

想像相等的「夾角 $\angle A = \angle D$」是一個角度固定不變的機械關節。

2. 伸展臂同比例伸縮（兩邊成比例）：

夾住這個角的兩條邊，依照相同的比例伸縮：

$$\frac{AB}{DE} = \frac{AC}{DF} = k$$

那麼，把兩臂端點連起來所形成的第三邊（底邊），就一定會是完美的縮放圖形，形狀唯一鎖定！

⚠️
易錯觀念避坑指南

為什麼不能是「SSA」？

🚨 嚴格限制：相等的角「必須」是兩等比邊所夾的角！

如果相等的角不是夾角（即 SSA），根據幾何作圖，可能會在圓弧交點處形成「銳角三角形」與「鈍角三角形」兩種截然不同的形狀，無法唯一鎖定圖形！

❌ SSA 相似不存在！（除直角 RHS 特例可轉化為 SSS 外，一般三角形 SSA 不保證相似）
